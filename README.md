# 👑 공주님 옷 입히기

HTML + Google Apps Script로 만든 2D 옷 입히기 게임입니다.

## 파일
- `Code.gs` — 서버 코드 (웹 앱 화면 띄우기, 옷차림 저장/불러오기)
- `Index.html` — 게임 화면 (공주님 그림은 SVG로 직접 그림, 이미지 파일 필요 없음)

## 구글 앱스 스크립트에 올리는 방법
1. https://script.google.com 에서 **새 프로젝트**를 만듭니다.
2. `Code.gs` 내용을 그대로 붙여 넣습니다.
3. 왼쪽 **파일 +** → **HTML** → 이름을 `Index` 로 만들고 `Index.html` 내용을 붙여 넣습니다.
4. **배포 → 새 배포 → 유형 선택: 웹 앱**
   - 실행 사용자: *웹 앱에 액세스하는 사용자* (각자 자기 서랍에 저장됨)
   - 액세스 권한: 원하는 범위 선택
5. 나온 웹 앱 주소로 접속하면 게임 시작!

## 게임 기능
- 옷장: 드레스 5종 · 머리 6종 · 신발 5종 · 머리장식 · 목걸이 · 소품 · 표정 · 피부색 · 배경 4종
- 드레스/머리/신발은 색깔도 바꿀 수 있어요
- 🎲 랜덤 코디, 🔄 처음으로, 📸 사진(PNG) 저장
- 💾 서랍 3칸에 옷차림 저장/불러오기 (구글 계정에 저장, 로컬로 열면 브라우저에 저장)
- 공주님 이름 붙이기

`Index.html`은 앱스 스크립트 없이 브라우저에서 바로 열어도 동작합니다.
