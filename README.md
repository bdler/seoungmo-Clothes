# 👑 공주님 옷 입히기

옛날 플래시 옷 입히기 게임처럼 **옷을 끌어다 공주님에게 놓으면 쏙 입혀지는** 2D 게임입니다.
HTML 한 파일 + Google Apps Script(`Code.gs`)로 되어 있어요.

## 파일
- `Index.html` — 게임 화면. 직접 그린(SVG) 공주님·옷 45가지가 들어 있고, AI 그림 공주님·옷은 `assets` 폴더에서 불러와요.
- `Code.gs` — 웹 앱으로 화면을 띄우고, 옷차림을 서랍 3칸에 저장/불러오기 합니다.

## 구글 앱스 스크립트에 올리는 방법
1. https://script.google.com 에서 **새 프로젝트**를 만듭니다.
2. `Code.gs` 내용을 붙여 넣습니다.
3. 왼쪽 **파일 +** → **HTML** → 이름을 `Index` 로 하고 `Index.html` 내용을 붙여 넣습니다.
4. **배포 → 새 배포 → 유형: 웹 앱**
   - 실행 사용자: *웹 앱에 액세스하는 사용자* (사람마다 자기 서랍에 저장)
5. 나온 주소로 접속하면 게임 시작!

## AI 그림 공주님 (assets/princess/body)
캔바 AI로 만든 **온몸 그림** 6장을 씁니다. 공주님마다 피부색과 머리색이 달라요.

| 파일 | 공주님 |
|---|---|
| `rose` | 로즈 — 적갈색 웨이브 머리, 밝은 피부 |
| `sunny` | 써니 — 금발, 밝은 피부 |
| `luna` | 루나 — 검은 머리, 따뜻한 밝은 피부 |
| `coco` | 코코 — 짙은 갈색 곱슬머리, 갈색 피부 |
| `amber` | 앰버 — 밤색 머리, 올리브 피부 |
| `peach` | 피치 — 분홍 머리, 밝은 피부 |

- 게임이 GitHub 저장소 기본 브랜치(raw.githubusercontent)에서 `<이름>.png`를 불러와요. 불러오는 동안에는 "공주님 부르는 중…" 이 보여요.
- 흰 배경을 자동으로 지우고, **분홍 튜브탑·반바지 위치를 찾아** 옷이 맞춰진 몸에 자동으로 맞춰요(다리 길이도 따로 맞춤).
  그래서 새 공주님을 만들 때도 같은 분홍 속옷, 같은 자세로 만들면 돼요.
- 그림 크기는 300×600 png예요. 더 큰 그림을 **같은 이름의 .png** 로 올리면 더 선명해져요.
- 파일을 못 찾으면 자동으로 ✏️ 직접 그린 공주님이 나와요.

## AI 그림 옷 (assets/princess/clothes)
로즈 공주님 그림에 옷만 입혀 캔바 AI로 다시 그린 뒤, **옷 부분만 오려 낸** 투명 png 14벌이에요.
로즈 그림과 같은 자리에 있어서, 다른 공주님에게도 몸에 맞춰 입혀져요.
🤖 AI 그림체일 때는 상의·하의·드레스·신발 칸에 AI 옷이 나오고, ✏️ 직접 그린 그림체일 때는 직접 그린 옷이 나와요.

| 칸 | 옷 (파일 이름) |
|---|---|
| 상의 | 리본 블라우스 `top_blouse` · 세일러 티셔츠 `top_sailor` · 하트 스웨터 `top_sweater` |
| 하의 | 청치마 `skirt_denim` · 발레 튀튀 `skirt_tutu` · 청바지 `pants_jeans` |
| 드레스 | 장미 `dress_rose` · 하늘빛 `dress_blue` · 왕실 `dress_red` · 요정 `dress_fairy` · 데이지 원피스 `dress_daisy` |
| 신발 | 반짝 구두 `shoes_flats` · 빨간 장화 `shoes_boots` |
| 액세서리 | 보석 티아라 `head_tiara` |

## 노는 방법
- 오른쪽 옷장에서 옷을 **끌어다 공주님 위에 놓으면** 입혀져요. (마우스 / 터치 모두 가능)
- 공주님이 입은 옷을 **끌어서 밖에 놓으면** 벗겨져서 옷장으로 돌아가요.
- 드레스를 입으면 상의·하의가 벗겨지고, 상의·하의를 입으면 드레스가 벗겨져요.
- 옷장 칸: 👚 상의 · 👖 하의 · 👗 드레스 · 👠 신발·가방 · 👑 액세서리 · 💇‍♀️ 머리(머리 모양/색, 피부색)
- 아래 버튼: **원래대로**(옷 모두 벗기기) · **랜덤** · **전체모습**(옷장 숨기고 공주님만 보기) · **사진**(PNG) · **저장**(서랍 3칸)

`Index.html`은 앱스 스크립트 없이 브라우저에서 바로 열어도 동작합니다(이때 저장은 브라우저에).
