# 👑 공주님 옷 입히기

옛날 플래시 옷 입히기 게임처럼 **옷을 끌어다 공주님에게 놓으면 쏙 입혀지는** 2D 게임입니다.
HTML 한 파일 + Google Apps Script(`Code.gs`)로 되어 있어요.

## 파일
- `Index.html` — 게임 화면. 공주님과 옷 45가지를 모두 SVG로 직접 그려서 이미지 파일이 필요 없어요.
- `Code.gs` — 웹 앱으로 화면을 띄우고, 옷차림을 서랍 3칸에 저장/불러오기 합니다.

## 구글 앱스 스크립트에 올리는 방법
1. https://script.google.com 에서 **새 프로젝트**를 만듭니다.
2. `Code.gs` 내용을 붙여 넣습니다.
3. 왼쪽 **파일 +** → **HTML** → 이름을 `Index` 로 하고 `Index.html` 내용을 붙여 넣습니다.
4. **배포 → 새 배포 → 유형: 웹 앱**
   - 실행 사용자: *웹 앱에 액세스하는 사용자* (사람마다 자기 서랍에 저장)
5. 나온 주소로 접속하면 게임 시작!

## 노는 방법
- 오른쪽 옷장에서 옷을 **끌어다 공주님 위에 놓으면** 입혀져요. (마우스 / 터치 모두 가능)
- 공주님이 입은 옷을 **끌어서 밖에 놓으면** 벗겨져서 옷장으로 돌아가요.
- 드레스를 입으면 상의·하의가 벗겨지고, 상의·하의를 입으면 드레스가 벗겨져요.
- 옷장 칸: 👚 상의 · 👖 하의 · 👗 드레스 · 👠 신발·가방 · 👑 액세서리 · 💇‍♀️ 머리(머리 모양/색, 피부색)
- 아래 버튼: **원래대로**(옷 모두 벗기기) · **랜덤** · **전체모습**(옷장 숨기고 공주님만 보기) · **사진**(PNG) · **저장**(서랍 3칸)

`Index.html`은 앱스 스크립트 없이 브라우저에서 바로 열어도 동작합니다(이때 저장은 브라우저에).
